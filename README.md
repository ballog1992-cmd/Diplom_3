
## Задание 3: Автотесты для UI (Stellar Burgers)

### UI-автотесты для проверки веб-интерфейса сервиса Stellar Burgers

Проект содержит автоматизированные тесты для проверки ключевого функционала фронтенда, включая работу с корзиной, ингредиентами и личным кабинетом.

### Реализованные сценарии

Тесты покрывают следующие области:
- **Конструктор:** переход к разделам ингредиентов, работа со счетчиками.
- **Ингредиенты:** открытие модальных окон с деталями.
- **Заказы:** создание заказа, отображение в ленте, работа счетчиков "Выполнено за все время/сегодня".
- **Личный кабинет:** вход, выход, регистрация и восстановление пароля.

### Структура проекта

- `methods/` — базовые и специфичные Page Object методы (BasePage, IngPageMethods и др.).
- `locators/` — файлы с локаторами элементов (CSS_SELECTOR, XPATH).
- `tests/` — пакет с тестами, разделенными по функциональным блокам.
- `conftest.py` — конфигурация pytest, фикстуры драйвера и авторизации.
- `data.py` / `helper.py` — генерация фейковых данных (Faker) и константы.

### Запуск автотестов

**Установка зависимостей**
> `pip install -r requirements.txt`

**Запуск тестов в разных браузерах**
Тесты поддерживают кроссбраузерный запуск через параметр `--browser`.

> `pytest --browser=chrome tests/test_burger.py`
> `pytest --browser=firefox tests/test_burger.py`

### Отчетность (Allure)

**Посмотреть отчет в браузере**
> `allure serve allure-results`
